# Pir Servo Buzzer Arduino

PIR sensörü, servo motor ve buzzer kullanan Arduino projesidir.

## Açıklama

Hareket algılayan PIR sensörünü kullanarak, insan hareketi tespit edildiğinde servo motor harekete geçer ve buzzer ses çıkarır. Güvenlik sistemi veya uyarı mekanizması olarak kullanılabilir.

## Kullanım

1. Arduino kartını bilgisayara USB ile bağla
2. Arduino IDE'yi aç
3. `PirServoBuzzerArduino.ino` dosyasını yükle
4. PIR sensörüne kablo bağla
5. Servo ve buzzer'ı devreye alma yapılandırmasına göre bağla
6. Hareketi algıla ve testini yap
